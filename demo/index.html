MiniOS 微型操作系统模拟平台

MiniOS 是一个 C11/POSIX 用户态 MiniKernel。系统在同一运行环境中维护 PCB、tick 调度、首次适应内存、在线 VM frame table、TinyFS、fd 表、同步场景、实时调度和状态测试；Shell、Workbench 与可视化轨迹共同呈现系统运行状态。

运行流程

完整运行从启动状态开始，按 tick 推进进程调度、内存分配、VM 访问和 TinyFS 操作，并生成可复查的验收记录。

1. 启动初始化 PCB、调度器、FF 内存、TinyFS、VM 和 dmesg。
2. 负载创建 shell/editor/compiler/logger/renderer，形成 READY、RUNNING、MEM_WAIT 状态。
3. 时钟RR、sleep、timer IRQ、MLFQ 降级和 aging 通过 tick 逐步触发。
4. 存储通过 TinyFS 和 fd 表写入项目文件、构建日志并验证镜像。
5. 验证执行 realtime、sync、tracebench、autotune，并从 dmesg 读取系统事件时间线。
